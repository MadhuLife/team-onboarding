# Madhu Life — Team Onboarding

Welcome to the team. This guide will walk you through everything you need to get set up and access all our shared resources — even if you have never used GitHub or Obsidian before.

There are no technical skills required. Follow the steps in order and you will be done in under 30 minutes.

---

## What You Will Set Up

| Tool | What It Does |
|---|---|
| **GitHub** | Cloud storage for all our shared files, docs, and code |
| **GitHub Desktop** | An app that lets you download and sync GitHub repos without any coding |
| **Obsidian** | An app that lets you read and navigate all our documents beautifully |

---

## The Process At A Glance

1. Create a GitHub account and send your username to Dr-mkelvo
2. Wait for your repository invitation email from GitHub
3. Install GitHub Desktop and clone the repos to your computer
4. Install Obsidian and open the repo as a vault
5. You are in
