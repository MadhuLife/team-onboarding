# Step 2 — Install GitHub Desktop and Clone the Repos

## What Is GitHub Desktop?

GitHub Desktop is a free app that connects your computer to GitHub. Once installed, it downloads copies of the team repositories directly to your computer so you can open, read, and work with all the files — no coding or command-line required.

Before starting this step, make sure you have:
- Completed Step 1 (GitHub account created, email verified)
- Accepted all repository invitations from Dr-mkelvo

---

## Install GitHub Desktop

### On Windows

1. Go to [https://desktop.github.com](https://desktop.github.com)
2. Click **Download for Windows**
3. Open the downloaded file (it will be named something like `GitHubDesktopSetup-x64.exe`)
4. Windows may ask if you want to allow the app to make changes — click **Yes**
5. GitHub Desktop will install automatically and open when done

### On Mac

1. Go to [https://desktop.github.com](https://desktop.github.com)
2. Click **Download for macOS**
3. Open your **Downloads** folder and find the file named `GitHubDesktop.zip`
4. Double-click it to unzip — this creates the **GitHub Desktop** app
5. Drag **GitHub Desktop** into your **Applications** folder
6. Open it from Applications or Launchpad

---

## Sign In to GitHub Desktop

1. When GitHub Desktop opens, click **Sign in to GitHub.com**
2. Your browser will open and ask you to authorize GitHub Desktop — click **Authorize desktop**
3. If prompted, click **Open GitHub Desktop** to return to the app
4. GitHub Desktop will now show your account name in the top-left corner

---

## Clone the Repositories

Cloning means downloading a copy of a repository from GitHub to your computer. You need to do this for each repository.

Repeat the following steps for each of the 5 repositories:

1. In GitHub Desktop, click **File** in the top menu bar
2. Click **Clone Repository...**
3. The **Clone a Repository** window will open
4. Click the **GitHub.com** tab — all repositories you have been invited to will appear in the list
5. Find the repository you want (e.g. `MadhuLife/madhu-life`)
6. Under **Local Path**, choose where to save it on your computer:
   - **Recommended on Windows:** `C:\Users\YourName\Documents\MadhuLife\`
   - **Recommended on Mac:** `/Users/YourName/Documents/MadhuLife/`
7. Click **Clone**
8. Wait for the download to complete — a progress bar will appear

Repeat for all 5 repositories:

| Repository | What It Contains |
|---|---|
| `MadhuLife/madhu-life` | Core strategy docs |
| `MadhuLife/company-docs` | All SOPs and business PDFs |
| `MadhuLife/ai-video-organizer` | Video and AI tools |
| `MadhuLife/claude-for-coaches` | Coaching templates and scripts |
| `MadhuLife/leads` | Lead research and outreach data |

## Keeping Your Repos Up To Date

When new files are added or updated by the team, your local copy will not update automatically. To get the latest version:

1. Open GitHub Desktop
2. Click on the repository you want to update (left sidebar)
3. Click **Fetch origin** in the top bar
4. If updates are available, it will change to **Pull origin** — click that

Do this at the start of each workday to make sure you always have the latest files.

---

## What The Buttons Mean

| Button | What It Does |
|---|---|
| Fetch origin | Checks if there are any updates on GitHub |
| Pull origin | Downloads the latest updates to your computer |
| Current branch | Shows which version of the files you are viewing |
