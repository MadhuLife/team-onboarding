# Step 3 — Set Up Obsidian

## What Is Obsidian?

Obsidian is a free note-taking and knowledge management app. We use it as the team's internal knowledge base viewer. When you open one of our GitHub repositories in Obsidian, it turns all the markdown files into a clean, readable, linked document system — like a private Wikipedia for the team.

Obsidian works entirely offline and stores everything locally on your computer. Nothing is uploaded to Obsidian's servers unless you specifically choose to use their optional sync feature (we do not use that for this project).

Before starting this step, make sure you have:
- Completed Step 2 (GitHub Desktop installed and all repos cloned)

---

## Install Obsidian

### On Windows

1. Go to [https://obsidian.md](https://obsidian.md)
2. Click **Get Obsidian for Windows**
3. Open the downloaded installer file (named something like `Obsidian-x.x.x.exe`)
4. Click **Yes** if Windows asks for permission
5. Follow the installer — click **Next**, accept the license, and click **Install**
6. Click **Finish** — Obsidian will open automatically

### On Mac

1. Go to [https://obsidian.md](https://obsidian.md)
2. Click **Get Obsidian for macOS**
3. Open your **Downloads** folder and find the `.dmg` file (e.g. `Obsidian-x.x.x.dmg`)
4. Double-click the `.dmg` file to open it
5. Drag the **Obsidian** icon into your **Applications** folder
6. Eject the installer by right-clicking it on the Desktop and selecting **Eject**
7. Open Obsidian from Applications or Launchpad
8. If Mac says it cannot open because the developer is unknown: go to **System Settings → Privacy & Security** and click **Open Anyway**

---

## Open a Repository as a Vault

In Obsidian, a **vault** is just a folder on your computer. When you open one of our cloned repositories as a vault, Obsidian reads all the files in that folder and presents them as a connected knowledge base.

1. Open Obsidian
2. On the welcome screen, click **Open folder as vault**
3. A file browser window will open
4. Navigate to the folder where you cloned the repository in Step 2:
   - **Windows example:** `C:\Users\YourName\Documents\MadhuLife\madhu-life`
   - **Mac example:** `/Users/YourName/Documents/MadhuLife/madhu-life`
5. Select the repository folder and click **Open** (Mac) or **Select Folder** (Windows)
6. Obsidian may ask **Do you trust the authors of the files in this vault?** — click **Trust authors and enable all features**
7. The vault will open and you will see the file list on the left side

Repeat this for each repository you want to browse. You can switch between vaults at any time.

---

## Adding Multiple Vaults

You do not need to re-open each vault every time. Obsidian remembers all vaults you have added.

To add another repository as a vault:

1. Click the small vault icon at the bottom-left of the Obsidian window (it looks like a stack of books)
2. Click **Open another vault**
3. Click **Open folder as vault**
4. Select the next cloned repository folder
5. Click **Open** or **Select Folder**

To switch between vaults:

1. Click the vault icon at the bottom-left
2. Click the name of the vault you want to open

## How Obsidian Works

Once your vault is open, here is what you will see:

| Area | What It Does |
|---|---|
| **Left sidebar** | File browser — shows all your folders and files |
| **Main panel** | Where documents open and display |
| **Right sidebar** | Shows linked documents and outline (can be hidden) |

**Opening a file:** Click any file in the left sidebar to open it in the main panel.

**Searching:** Press `Ctrl + F` (Windows) or `Cmd + F` (Mac) to search inside the current document. Press `Ctrl + Shift + F` or `Cmd + Shift + F` to search across all files in the vault.

**Following links:** If a document links to another document, you can click the link and Obsidian will jump directly to that file.

**Reading mode vs editing mode:** By default you are in reading mode. Click the pencil icon in the top-right of the document to switch to editing mode. Unless you are asked to edit files, stay in reading mode.

---

## Important: Do Not Edit Files Without Permission

Obsidian lets you edit documents directly. However, any changes you save locally will not automatically sync back to GitHub — and may create conflicts. Unless you are specifically asked to make changes, use Obsidian for reading and navigation only.

If you need to make edits, speak to Dr-mkelvo first.
